# Crop: Grapes (Vitis vinifera)
- **Soil Suitability:** Well-drained sandy loam to red loams (pH 6.5 - 8.0).
- **Pruning Schedule:** Foundation / April pruning (Back pruning for cane growth); Fruit / October pruning (Forward pruning for fruit bunches).
- **Nutrient Management:** Balanced fertigation using water-soluble fertilizers (0:52:34, 13:0:45, Calcium Nitrate).
- **Disease Management:** Downy mildew (*Plasmopara viticola*) managed with Bordeaux mixture 1% or Metalaxyl-Mancozeb.
