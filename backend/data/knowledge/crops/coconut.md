# Crop: Coconut (Cocos nucifera)
- **Soil Suitability:** Coastal sandy, alluvial, and red laterite soils with good drainage (pH 5.5 - 7.5).
- **Nutrient per Palm/Year:** 500g N, 320g P2O5, 1200g K2O + 50 kg FYM + 1 kg Magnesium Sulphate.
- **Pest Management:** Rhinoceros beetle managed with Rhinolure pheromone traps and Naphthalene balls placed in leaf axils; Red Palm Weevil managed with Ferrolure traps.
